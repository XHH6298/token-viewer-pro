# 窗口与设置修复（2026-10-02）

## 修改

- 首次页面加载后，在 UI 线程重建 WinForms 初始合成表面：宽度暂增一个物理像素，下一 UI 时钟恢复；不切换全屏。已有用户尺寸变化时不覆盖该变化。
- 在窗口创建完成、句柄重建、获得焦点、恢复窗口、尺寸变化时应用 DWM 背景；普通窗口显式使用圆角，胶囊模式保留其裁剪区域。
- 普通窗口保留 WS_THICKFRAME，为 DWM 提供实际圆角所需的边框样式。自定义非客户区计算避免增加系统边框，并恢复边缘拖动缩放；全屏移除该样式。
- UI 缩放统一使用 90%、100%、110%，涵盖设置、快捷键、Ctrl + 滚轮和旧配置迁移；关闭 WebView2 独立的用户缩放。
- 使用持久 WebView2 配置保存本地设置。保留语言参数与数据库语言兜底。
- 支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语和意大利语。
- 新增错误提示、空状态、胶囊与侧栏提示翻译；设置卡片与定价操作区允许换行。
